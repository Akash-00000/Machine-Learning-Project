# Contributing to Speaker Recognition Project

Thank you for your interest in contributing! Here's how to get started.

## How to Contribute

1. **Fork** the repository
2. **Create a branch**: `git checkout -b feature/your-feature-name`
3. **Make your changes** and test them
4. **Commit**: `git commit -m "Add: brief description of change"`
5. **Push**: `git push origin feature/your-feature-name`
6. Open a **Pull Request** describing what you changed and why

## Ideas for Contributions

- New ML models (e.g., deep learning with CNNs or LSTMs)
- Better audio feature engineering
- Noise augmentation / robustness testing
- Streamlit or Flask demo app
- Dataset preprocessing scripts

## Code Style

- Follow PEP 8 for Python code
- Add comments to non-obvious code sections
- Keep notebook cells focused — one task per cell
- Include print statements or visualizations to show outputs

## Reporting Issues

Open a GitHub Issue with:
- A clear title
- What you expected to happen
- What actually happened
- Steps to reproduce
